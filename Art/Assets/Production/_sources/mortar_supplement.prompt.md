# Mortar supplement generation prompt

Built-in ImageGen was used with the existing scale, mortar, and gameplay concept images as style/world references.

```text
Use case: stylized-concept
Asset type: production supplement sprite sheet for a 2D mobile game
Input images: Image 1 is the brass balance style reference; Image 2 is the brass mortar-and-pestle design master and must define the exact painterly material/style; Image 3 is the Persian alchemist shop world and palette reference.
Primary request: Create one clean component sheet containing exactly SEVEN separate, non-overlapping mortar-related sprite elements: (1) a top-view shallow oval cluster of raw herbs and petals sized to sit inside the reference mortar, (2) a matching top-view shallow oval mound of finely crushed muted violet-green herbal powder, (3) one small airborne olive-green leaf fragment, (4) one small burgundy petal fragment, (5) one small ochre seed fragment, (6) a compact stylized dust-impact puff, (7) a second slightly wider dust-impact puff. All elements must be fully visible, isolated, and separated by generous empty space.
Style/medium: final-game 2D stylized painterly, Persian-inspired Kimiyagar art direction, warm upper-left light, broad painted shapes, low micro-detail, soft controlled dark-brown edges, handmade and tactile.
Composition/framing: seven components arranged in a simple spacious grid; no overlap; no mortar body and no pestle.
Scene/backdrop: perfectly flat solid #ff00ff chroma-key background for background removal; absolutely uniform, no shadow, gradient, texture, floor, or lighting variation.
Color palette: restrained herbal olive, muted violet, burgundy and ochre; dust is warm parchment-brown; no magenta in any sprite.
Constraints: crisp silhouette at mobile size; every component fully separated from background; no cast shadow, no contact shadow, no reflection; no labels, text, letters, numbers, logo, watermark, border, UI, environment, or extra objects.
Avoid: photorealism, glossy 3D, childish cartoon, Western fantasy, steampunk, neon glow, excessive particles.
```
