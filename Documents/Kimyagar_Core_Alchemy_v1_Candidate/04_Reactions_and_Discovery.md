# 04 --- Reactions, Synergy & Discovery

## 1. Shared Rule Concept

Synergy، Hidden Property و Layer D باید تا حد ممکن از یک Rule Model
مشترک استفاده کنند.

Rule ممکن است Conditionهایی از این جنس داشته باشد: - Property
condition - Ingredient condition - Process condition - Quantity
condition - Progression/knowledge condition

Result: - modifier - quality tag - reveal/activate hidden property -
transform/create property - discovery event

## 2. Synergy

Synergy الزاماً Property جدید نیست.

مثال: `Calm + Sleep → Restful`

Restful می‌تواند **Quality Tag** باشد.

Property پاسخ می‌دهد: \> Potion چه اثری دارد؟

Quality Tag پاسخ می‌دهد: \> این اثر چگونه اتفاق می‌افتد؟

Tagها باید محدود و Contextual باشند.

## 3. Hidden Properties

Ingredient می‌تواند Property پنهانی داشته باشد که فقط در Process خاص فعال
شود.

Mechanical truth از Player knowledge جداست: - Active = true - Discovered
= false

Potion می‌تواند اثری داشته باشد که بازیکن هنوز نامش را نمی‌داند.

## 4. Discovery State

سه وضعیت: - Unknown - Observed - Confirmed

اولین مشاهده می‌تواند Notebook clue بدهد. تکرار/تأیید، دانش را Confirm
می‌کند.

## 5. Layer D --- Emergent Reactions

Late-game system برای مشتری‌های خاص و سفارش‌های گران/سخت.

اصل: \> **Emergent Reaction بیشتر Transformation است تا Bonus.**

مثال مفهومی: `Dream + Mythical Catalyst + Special Heat → Vision`

ممکن است بخشی از Property ورودی مصرف/تبدیل شود.

## 6. Reaction Priority

Pipeline: 1. Base Extraction 2. Axis Resolution 3. Hidden Property
Activation 4. Synergy Evaluation 5. Layer D Reaction 6. Recalculate
Axis/Tension 7. Stability 8. Final Potion Evaluation

## 7. No Reaction Chains in v1

هر Rule حداکثر یک بار در Brew اجرا شود. خروجی D Reaction دوباره D
Reaction دیگری را Trigger نمی‌کند مگر در نسخه‌ی آینده به‌طور عمدی طراحی
شود.

## 8. Data-driven, not overengineered

Engine نباید نام Simurgh Feather را بشناسد؛ باید مفهوم
`required_ingredient` را بشناسد. با این حال Prototype اول نیازمند
Universal Reaction Framework کامل نیست.

## 9. Discovery Feedback

هر Discovery باید Feedback کوتاه و باارزش داشته باشد: - Sound -
Animation - Haptic

Flow نباید متوقف شود.
